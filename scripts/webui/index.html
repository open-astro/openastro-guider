Static Polar Alignment

Point near the celestial pole, loop and select a star, then start. Auto mode rotates a goto mount by itself; manual mode: rotate ≥ 0h20m in RA between points.

Adjustment
Polar Drift Alignment

Point near the pole, loop and select a star, then start and let it accumulate — the longer it drifts, the better the estimate. Guide output is disabled while measuring. Adjust alt/az to move the star to the target, then restart.

Drift
Drift Alignment

Needs a calibrated mount. Azimuth phase: point near meridian × equator. Altitude phase: point near the east/west horizon. Drift watches the dec trendline; Adjust locks a reference so you can re-centre the star with the bolt.
